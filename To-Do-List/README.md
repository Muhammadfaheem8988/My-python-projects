**Simple Python To-Do List**

A lightweight, command-line interface (CLI) application built with Python that helps you manage your daily tasks. This project demonstrates basic Python concepts like lists, dictionaries, loops, and user input handling.
----

**Features**

Add Tasks: Quickly add new items to your list.

View Tasks: See all your tasks with their current completion status.

Mark Completion: Check off tasks as you finish them.

Interactive Menu: Easy-to-use numbered menu system.
----

**How to Run**

Prerequisites: Ensure you have Python installed (version 3.x is recommended).

Download: Save the script file (e.g., to_do_list.py) to your computer.

Execute: Open your terminal or command prompt, navigate to the folder containing the file, and run:

Bash

python to_do_list.py

 Usage Example
 
Once the program starts, follow the on-screen prompts:

Select 1 to type in a new task.

Select 2 to list everything you need to do.

Select 3 to mark a specific task as done by entering its number.

Select 4 to exit the program.
